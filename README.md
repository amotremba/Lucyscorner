# Lucy's Corner

  ## Linking a post to Substack

  Add a `substack:` key to a post's front matter with the full Substack URL:

  ```yaml
  ---
  layout: post
  title: "The Summer-to-Fall Itch"
  date: 2026-09-18
  tag: "FAVORITE FINDS"
  substack: https://anneotremba.substack.com/p/summer-to-fall-itch
  ---
  ```

  Posts with the key get an "Also on Substack" call-to-action below the article
  and a badge on the blog index. Posts without it render exactly as before. 🐾
