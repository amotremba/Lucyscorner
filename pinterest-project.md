## Workflow

1. For **story pins**: use the photo noted for that day (already in the repo/rotation-fixed where noted), add the title as a light text overlay in Canva if desired, and export as PNG/JPG. For **quote pins**: build a simple text-forward card in Canva with the title as the main line.
2. Post manually to Pinterest (anne8133 → Social board), using that day's title as the Pinterest title, the description as the pin description, and the linked story URL as the destination link (not the homepage — the whole point is that the link matches what the pin promises).
3. Check off the "Posted?" box above.
4. After 2 weeks + 100 views/month → reconnect Blotato for auto-scheduling.
